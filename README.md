# VYOMA's Grand Tapestry

Build a polished, visually spectacular interactive frontend prototype for VYOMA exactly as requested. Prioritize the complete clickable journey Home → Explore Heritage → Mahabharata → Draupadi’s Vastraharan scene experience. Make the scene experience the wow moment with working play/pause/restart timeline, progressive word-synced captions, multilingual mock narration/transcript selection, clickable character cards/details, interactive knowledge graph with linked highlights, and an upward-projecting tabletop holographic VYOMA hardware activation sequence. Use local/mock data only, premium cinematic Indian heritage × futuristic museum visual design, smooth navigation, and add the requested Explore, Knowledge Graph, Heritage pages plus global search. Do not spend time on a backend; make the UI and interactions fully polished and demo-ready.
